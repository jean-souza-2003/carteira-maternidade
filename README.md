# Carteira de Trabalho: maternidade e paternidade

Página interativa em formato de carteira de trabalho, com os direitos de quem vai ter ou adotar um filho: pré-natal, estabilidade, mudança de função, licença-maternidade, amamentação, licença-paternidade, as mudanças da Lei 15.371/2026, adoção e um quiz de mito ou verdade.

Trabalho acadêmico do curso de Direito, Universidade de Mogi das Cruzes, 2026. Regras em vigor em novembro de 2026.

## Como abrir

Acesse o link do GitHub Pages deste repositório (Settings > Pages) ou escaneie o QR Code do trabalho. Para virar as folhas, deslize para o lado ou use os botões Anterior e Próxima.

## Como atualizar

Envie um novo `index.html` com o mesmo nome em Add file > Upload files. O site atualiza em alguns minutos.

## Arquivos

- `index.html`: a página completa (HTML, CSS e JavaScript num arquivo só)
- `favicon.svg` e `apple-touch-icon.png`: ícones da aba do navegador e da tela inicial do celular
